## איך פותחים

אין שרת, אין התקנה ואין שלב בנייה.

1. מורידים את התיקייה (או משכפלים אותה עם git, הסבר בהמשך).
2. לוחצים לחיצה כפולה על `index.html`.

זהו. האתר רץ ישר מהדיסק (`file://`). צריך אינטרנט רק כדי לפתוח את האתרים עצמם ולטעון את הלוגואים. בלי אינטרנט מופיע במקום הלוגו אייקון של הקטגוריה.

## מה יש בפנים

- כרטיס לכל כלי: לוגו, שם, תיאור קצר בעברית, תגית מחיר (חינמי או מסלול חינמי) ותגית 💎 לפנינה נסתרת. לחיצה על הכרטיס פותחת את האתר בלשונית חדשה.
- חיפוש מיידי לפי שם, תיאור או קטגוריה. מקש `/` קופץ לחיפוש, ו-`Esc` מנקה אותו.
- סינון לפי קטגוריה, מועדפים או פנינים.
- ⭐ מועדפים שמוצמדים לראש הדף, ו-🕘 רשימה של כלים שנפתחו לאחרונה.
- ערכת צבעים כהה (ברירת מחדל) ובהירה, ותצוגה שמתאימה גם לטלפון.
- ניווט מלא במקלדת: Tab, חיצים בין כרטיסים, Enter לפתיחה.

## הוספה, עריכה ומחיקה של כלים

הכל נעשה מתוך הדף עצמו:

- **הוספה:** כפתור "הוספת כלי" למעלה. מדביקים כתובת, השם והלוגו מתמלאים אוטומטית, ומשלימים תיאור, קטגוריה, מחיר והאם זו פנינה.
- **עריכה או העברה לקטגוריה אחרת:** מעבירים את העכבר על כרטיס ולוחצים על העיפרון.
- **מחיקה:** לוחצים על הפח ומאשרים. אחרי המחיקה מופיעה הודעה עם כפתור "ביטול" שמחזיר את הכלי.
- **קטגוריות:** בתפריט `⋯`, בוחרים "ניהול קטגוריות". שם אפשר להוסיף קטגוריה, לשנות שם ואייקון, לשנות סדר ולמחוק. כשמוחקים קטגוריה, הכלים שלה עוברים אל "שלוף, בלי קטגוריה".

השינויים נשמרים אוטומטית בדפדפן (`localStorage`). הם שייכים לדפדפן ולמחשב הספציפיים, ולכן כדאי לגבות.

## ייצוא, ייבוא ואיפוס

בתפריט `⋯`:

- **ייצוא לקובץ JSON:** שומר את כל הרשימה (כלים, קטגוריות ומועדפים) לקובץ בתיקיית ההורדות. זה הגיבוי שלכם, וגם הדרך לשלוח את הרשימה לחבר.
- **ייבוא מקובץ JSON:** בוחרים קובץ שיוצא קודם, ואז בוחרים בין שתי אפשרויות:
  - *מיזוג*: מוסיף רק כלים שעוד אין לכם.
  - *החלפה*: מחליף את כל הרשימה בתוכן של הקובץ.
- **איפוס לרשימת ברירת המחדל:** מוחק את כל השינויים וחוזר לרשימה המקורית שבקובץ `data/tools.js`.

## מבנה הקבצים

| קובץ | מה יש בו |
|---|---|
| `index.html` | מבנה הדף |
| `styles.css` | העיצוב, כולל ערכה כהה ובהירה |
| `app.js` | כל הלוגיקה |
| `data/tools.json` | רשימת ברירת המחדל (שדות: `id`, `name`, `url`, `description_he`, `category`, `free`, `gem`, `logo`) |
| `data/tools.js` | אותה רשימה בדיוק, עטופה ב-JS, כדי שהאתר יעבוד מ-`file://` בלי בעיות CORS |
| `tests/selftest.js` | בדיקה עצמית. פותחים את `index.html?selftest` בדפדפן ורואים את התוצאות |

### לשנות את רשימת ברירת המחדל בקוד

הדרך הפשוטה: עורכים בדף, מייצאים לקובץ JSON ושומרים אותו במקום `data/tools.json`. אחר כך מעדכנים את `data/tools.js` כך שיכיל את אותו תוכן אחרי `window.TOOLBOX_DEFAULT = `. האתר טוען את `data/tools.js`, ולכן שני הקבצים צריכים להיות זהים.

## שיתוף דרך git

**לשכפל ולפתוח:**

```bash
git clone https://github.com/<שם-המשתמש>/klaimans-toolbox.git
```

נכנסים לתיקייה ולוחצים פעמיים על `index.html`.

**לשמור שינויים ולהעלות:**

```bash
git add .
git commit -m "עדכון רשימת הכלים"
git push
```

שימו לב: שינויים שעושים בדף נשמרים בדפדפן ולא בקבצים. כדי שהם ייכנסו ל-git, מייצאים ומעדכנים את `data/tools.json` ו-`data/tools.js` כמו שמוסבר למעלה.

**דרך נוספת לשתף:** פשוט שולחים לחבר את קובץ ה-JSON שייצאתם, והוא מייבא אותו אצלו.
